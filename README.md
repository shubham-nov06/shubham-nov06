## 🚀 projects

<details open>
<summary><b>🌾 ExamPedia</b> — ai quiz platform for afo exam prep</summary>

<br/>

instead of a fixed question bank, ExamPedia generates **fresh practice questions on demand** using llms, so aspirants never run out of new material.

- 🧠 questions generated via the **Groq API** (`llama-3.3-70b-versatile`)
- ⚛️ frontend built with **React + Vite**
- 🔐 api keys handled through secure environment variables
- 🌍 deployed on **Netlify**
