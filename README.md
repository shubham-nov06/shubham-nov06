## 🚀 Featured Projects

### 🌾 ExamPedia
**AI-powered quiz platform for Agriculture Field Officer (AFO) exam preparation.**

Instead of a fixed question bank, ExamPedia generates fresh practice questions on demand, so aspirants never run out of new material to practice with.

- 🧠 Generates questions using LLMs through the **Groq API** (`llama-3.3-70b-versatile`)
- ⚛️ Frontend built with **React + Vite**
- 🔐 API keys handled through secure environment variables
- 🌍 Deployed on **Netlify**

## 🧭 How I Build

- **Start simple.** Reach for a single file before a framework, and add complexity only when it earns its place.
- **Ship, then refine.** A deployed v1 teaches more than a perfect plan.
- **Design matters.** Projects should look and feel professional, not auto-generated.
- **Keep secrets secret.** API keys live in environment variables, never in the repo.
